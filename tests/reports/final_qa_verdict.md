- 引擎数据一律落在 `.testscratch/`（项目内大磁盘）或 `EVERSEND_HOME` 指向的临时目录，

## 7. 仍然存在的风险 / 建议

1. **安卓只有静态断言**（§3）—— 交付说明里请明确写这句，别让它看起来像 QA 真机验过。
2. **README 画廊改网页布局时要同步**：现在 40 张引用全部可解析（E6 绿），
   下次改布局后跑 `--only E6` 立刻能发现坏图。
3. **`docs/screenshots/` vs `tests/screenshots/` 的语义**已写进 `screenshot_index.md`
   （前者是 README 画廊、三端都放；后者是测试产物、README 不引用；
   `EVERSEND_SHOT_DIR=docs/screenshots` 是重拍画廊的正式做法）。
4. **`tools/manual_scan_veth.py` 需要 `unshare -rn`**，不能进 CI；索引里写了预期输出，
   改扫描逻辑时请手工跑一次。
5. **绝对时间阈值在多任务机器上天然噪声大** —— 建议一律用相对判据。
   实证：实现方把 1000 行的判据从"<3 秒"改成"后半 500 行不得比前半慢 3 倍"之后，
   第一次跑就抓出一个 O(n²) 回归（前 0.201s / 后 1.201s）。
