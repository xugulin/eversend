## 验收（新 APK 装好后用同一探针复测）

```bash
cd eversend && EVERSEND_ADB_SERIAL=2430d3c EVERSEND_REAL_WORK=/home/xgl/qa-real \
DISPLAY=:99 QT_QPA_PLATFORM=xcb python3 tools/realdevice_probe.py --only A2 --label after-newapk
```

判据：
1. 传输中截图必须出现与真值一致的百分比（±3%）与速度（非零、单位正确）；
2. 完成后 2s 内卡片状态必须变成「已收到/已保存」且不再提供「保存」误导入口；
3. 批量条目「正在排队」必须在开始下载时变成进行中，而不是一直排队；
4. 会话标题不得出现内部 id。
